# GPCR salt bridges

Reproducible extraction of salt bridges from GPCR structures

Author: Jawaher Basalma ([ORCID 0009-0000-4159-2813](https://orcid.org/0009-0000-4159-2813))

Salt bridges between transmembrane helices act as conformational
switches in class A GPCRs. This project extracts them from experimental
structures and asks whether two independently generated extraction
pipelines, built from the same written specification, agree on what they
find. Expected output: a table of salt bridges per structure, the
agreement rate between the two pipelines, and a catalogue of the cases
where they disagree.

## Reproduce the results

You need [Pixi](https://pixi.prefix.dev/latest/) and an internet connection.
Then, from this folder:

```bash
pixi install          # builds the exact environment recorded in pixi.lock
pixi run reproduce    # downloads the raw data and rebuilds every result
```

`pixi run reproduce` must work on a fresh clone of this repository. A GitHub
Action (`.github/workflows/reproduce.yml`) checks that on every push.

## Data
Experimentally determined structures of class A GPCRs from the RCSB PDB
(https://www.rcsb.org/), covering both inactive and active states:
5–10 structures, a few MB in total, public domain. Downloaded by
`scripts/01_download_structures.py`. The structure list, source URLs,
access dates and SHA256 checksums are recorded in
`metadata/structures.csv`.

## Question and hypothesis

Does the ionic lock, a salt bridge between transmembrane helices 3 and 6,
break when a class A GPCR activates?

Hypothesis: the cytoplasmic ends of TM3 and TM6 are closer together in
inactive-state structures than in active-state ones, measured as the
distance between generic positions 3.50 and 6.30.

Secondary: a salt bridge between those two positions is present in
inactive structures and absent in active ones.

Comparison: six class A receptors, each solved in both states — rhodopsin,
beta-2 adrenergic, M2 muscarinic, mu-opioid, A2A adenosine and
kappa-opioid.

## Results

The distance hypothesis holds, with complete separation between the groups.
Every inactive structure has 3.50 and 6.30 closer together than every active
structure: 2.7 to 10.1 A inactive, 11.6 to 14.7 A active. Mann-Whitney
p = 0.004, which is the smallest value possible at these group sizes.

The salt bridge hypothesis does not. A bridge is detected in one of six
inactive structures and none of five active ones. Two receptors, mu- and
kappa-opioid, carry a leucine at 6.30 and cannot form the interaction at
all. In two others the acidic partner is present but too distant to
interact, including the beta-2 adrenergic receptor at 7.1 A, consistent
with published reports that its ionic lock is not formed.

So the helices separate reliably on activation, while the salt bridge
itself is rarer than the textbook account suggests.

## Output

`results/lock_status.csv` — per structure: the residues at 3.50 and 6.30,
whether a salt bridge is detected between them, and their closest approach.

`results/lock_test.json` — group counts, Fisher exact test on lock presence,
Mann-Whitney test on distances.

`data/processed/salt_bridges.csv` — every salt bridge found in every
structure, which the above is drawn from.
